# Storefront UI/UX pass — 22 September 2026

## Scope

Section-by-section review of the existing Mastt storefront, preserving its palette. Payment setup remains with the merchant's team. No catalogue content, prices, product statuses, or source-sheet values were changed in this pass.

## Changes and root causes

### Shared product cards

- Replaced three overlapping badge sources (legacy tag labels, a metafield ribbon, and rail labels) with one shared badge snippet. Priority: Sold out → `custom.card_badge` → section label → supported product tag → Sale. A card without applicable data has no badge.
- Removed obsolete hidden labels, duplicate rating markup and unused standard quick-add modal/form markup. Existing bulk-add support remains.
- Corrected conflicting price styles so regular and sale prices do not both display. Only the compare-at price is struck through. Price remains above the title, with the plus beside it.
- Titles can occupy two lines. Wishlist and plus controls have larger touch areas.
- Direct add now uses the variant's minimum quantity and displays an accessible confirmation with a View cart link, or an error message. Products requiring a variant choice still open their product page.

### Collections

- Restored the native collection heading, previously disabled in the template.
- Moved mobile Filter & Sort from a fixed bottom overlay into the row beside the product count.
- Restored numbered Shopify pagination. Removed the old infinite-scroll script, its artificial loading delay, spinner, and unused Judge.me observer.
- Faster filter response (300ms debounce), stale-response protection, bounded response cache, and a visible retry link after a failed update. Old requests cannot replace newer results.

### Product page

- Removed the inherited CSS rule that forced Add to Cart and Buy it now into separate rows. They now fit side by side at narrow mobile and desktop sizes.
- Expanded gallery dot tap areas to 28px without enlarging their visual dots. Added current-slide accessibility state and reduced-motion handling.
- Suppressed the empty grouping label when its metafield has no linked products. Grouping scroll controls no longer register duplicate handlers on every resize.

### Footer and promises

- Marked the custom footer link blocks as menus, corrected overriding Dawn styles, and placed Shop and Mastt Cares beside each other on mobile. Links remain a single readable list within each column.
- Reduced contact-detail typography and excess spacing while preserving all links and content.
- Promise images use `object-fit: contain` inside their square frames to avoid cropping.
