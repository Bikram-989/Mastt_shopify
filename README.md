# Mastt Shopify Theme

Mastt Jewellery storefront — Shopify Online Store 2.0 (Dawn-based).

- `assets/mastt-redesign.css` — brand design system (colors, type, tokens, components)
- `assets/mastt-redesign-tokens.css` file history/details in project chat
- Companion redesign brief and homepage preview: see Claude conversation artifacts

## Setup after import
- Upload logo/favicon via Theme Editor → Theme settings → Logo
- Upload product/collection photography and reassign in Theme Editor
- Populate `main-menu` / `footer` navigation
